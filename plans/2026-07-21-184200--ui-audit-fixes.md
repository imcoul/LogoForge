# UI Audit Fixes

## Summary
Fix 22 UI issues from the audit: critical duplication and accessibility gaps, high-severity missing styles and viewport breakage, medium/lower UX polish.

## High-Level Verdict
- **Go as a single agent pass.** Phases are ordered by dependency: foundation first (CSS tokens + extracted components), then the `Modal` wrapper (which depends on foundation), then ports and responsive fixes.
- **`SVGPathEditor` fullscreen is not a modal** — it is a viewport state toggle, excluded from Step 1.2.
- **`animate-in` / `fade-in-95` / `zoom-in-95` are vestigial** — `tailwindcss-animate` is not installed; these classes silently fail. Delete them and rely on existing `motion.div` `animate` props.
- **Sheet becomes `MobileSheet`** — composes `Modal` internally for shared a11y, renders as bottom sheet on mobile only.
- **Z-index scale needs an overlay tier** for fullscreen editors and collab ghosts that legitimately sit above modals.

## Plan

### Phase 0 — Foundation
- **Step 0.1** (`src/index.css`): Define z-index scale via `@layer components`:
  - `z-dropdown` (40), `z-sticky` (50), `z-modal` (60), `z-overlay` (70), `z-toast` (80), `z-max` (9999)
  - Replace every `z-30`, `z-40`, `z-[99]`, `z-[100]`, and bare `z-50` on modals/overlays with scale tokens.
- **Step 0.2** (`src/index.css`): Add missing CSS utilities: `no-scrollbar`, `scrollbar-none`, `custom-scrollbar`. Replace `backdrop-blur-xs` with `backdrop-blur-sm` (3 occurrences — semantic equivalent). Delete `animate-fadeIn` usage if any; verify none exist.
- **Step 0.3** (`src/index.css`): Resolve custom shades. Extend `@theme` with exact `neutral-*`/`zinc-*` values OR replace every usage with standard Tailwind equivalents. Do not leave arbitrary values without a single source of truth.
- **Step 0.4**: Extract duplicated primitives into `src/components/ui/`:
  - `Tooltip.tsx` (from `App.tsx` and `Studio.tsx`)
  - `DesignChecklist.tsx` (from `App.tsx` and `Studio.tsx`)
  - `CustomWaveformPlayer.tsx` (from `App.tsx` and `Studio.tsx`)
  - `ANIMATIONS.ts` (from `App.tsx` and `Studio.tsx`)
  - `sanitizeSVG.ts` (from `App.tsx`, `Studio.tsx`, `Dashboard.tsx`, `SVGPathEditor.tsx`, `InteractiveMockupViewer.tsx`)
  - `safeFormatDate.ts` (from `App.tsx` and `Dashboard.tsx`)

### Phase 1 — Modal System
- **Step 1.1**: Add `focus-trap` to dependencies. Build `src/components/ui/Modal.tsx`:
  - `role="dialog"`, `aria-modal="true"`, `aria-labelledby` wired to a required `titleId` prop
  - Focus trap via `focus-trap` library
  - Escape key handler → `onClose`
  - Focus restoration to trigger element on close (store ref before open)
  - Backdrop click-to-close
  - z-index `z-modal` (60) from Phase 0 scale
  - Props: `isOpen`, `onClose`, `titleId`, `children`, optional `className` for size variants
- **Step 1.2**: Port every **dialog** to `Modal`:
  - `Whacanudo.tsx`
  - `ForgeAcademy.tsx` — also delete vestigial `animate-in fade-in zoom-in-95 duration-200` class; relies on Motion `animate` already present or add it
  - `KeyboardManager.tsx`
  - `VectorizePreviewModal.tsx`
  - `FigmaExportModal.tsx` — also delete `animate-in fade-in zoom-in-95 duration-200`; relies on Motion
  - `GoogleDriveIntegration.tsx` — change `z-[99]` to `z-modal`
  - `InteractiveMockupViewer.tsx`
  - `TouchGesturesHelp.tsx`
  - `Sheet.tsx` → **rename to `MobileSheet.tsx`**, compose internally with `Modal` for shared focus-trap + Escape + ARIA, keep bottom-sheet `md:hidden` behavior
- **Excluded from Step 1.2:** `SVGPathEditor.tsx` fullscreen mode. That is a viewport state, not a dialog. Handled in Phase 2.

### Phase 2 — Responsive & Overflow
- **Step 2.1**: Replace hardcoded viewport units with dynamic viewport units (`dvh`/`dvw`):
  - `WhiteboardCanvas` `h-[540px]` → responsive flex height (`min-h-[300px] h-[60dvh]`)
  - `SVGPathEditor` `w-[70vh] h-[70vh]` → `min-w-[320px] w-full max-w-[calc(100dvw-2rem)] aspect-square max-h-[calc(100dvh-4rem)]`
  - `AiPreviewSlider` `w-[400px]` → `w-[calc(100%-2rem)] max-w-[400px]`
  - All modal `max-h-[85vh]` / `h-[90vh]` / `h-[80vh]` → `max-h-[85dvh]` / `h-[90dvh]` / `h-[80dvh]` with `overflow-y-auto`
  - `Studio.tsx` empty state `min-h-[420px]` → remove or `min-h-[50dvh]`
- **Step 2.2**: `Sheet` rename is complete in Phase 1. Verify `MobileSheet` renders correctly on mobile and is hidden on desktop.
- **Step 2.3**: Add loading skeletons:
  - `Dashboard.tsx`: skeleton cards while `isHydrated` is false
  - `Course.tsx`: skeleton for lesson module content
  - `GoogleDriveIntegration.tsx`: clearer empty/error state copy + retry button
  - `FigmaExportModal.tsx`: retry button on failure state

### Phase 3 — Accessibility & UX Polish
- **Step 3.1**: Dashboard action buttons — remove `md:opacity-0` so buttons are always visible on desktop. Keep hover scale/color enhancement only.
- **Step 3.2**: Standardize disabled states — audit all `disabled:` usages, converge to `disabled:opacity-50 disabled:cursor-not-allowed`.
- **Step 3.3**: Replace `bg-[#800080]` with `bg-brand-lead` in `Settings.tsx` and `FigmaExportModal.tsx`.
- **Step 3.4**: Add `referrerPolicy="no-referrer"` to all `<img>` tags missing it.
- **Step 3.5**: Async ErrorBoundary — convert `ErrorBoundary.tsx` to functional component with `useState`. In `src/main.tsx`, attach `window.addEventListener('unhandledrejection', ...)` and `window.addEventListener('error', ...)` that call `setError(error)` on a shared state, passed into `ErrorBoundary` as a prop or context.
- **Step 3.6**: Fix `Whacanudo.tsx:113` — replace ternary with `const baseLang = i18n.language.split('-')[0]; const c = dict[baseLang] || dict.en;`.
- **Step 3.7**: Add "Show Gestures" button in `Settings.tsx` that calls `setIsVisible(true)` on a lifted `TouchGesturesHelp` state.
- **Step 3.8**: Throttle `handleGhostSync` in `App.tsx:1354-1363` to ≤30fps using `requestAnimationFrame` gate.
